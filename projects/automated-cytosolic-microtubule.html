Automated Cytosolic Microtubule Detection

A prototype deep-learning workflow for automated detection of cytosolic microtubule structures from fluorescence microscopy images, created to reduce repetitive manual quantification.

GitHub ↗

The problem

Manual identification of cytosolic microtubule structures is time-consuming and can introduce user bias. The project explores whether object detection can help automate this microscopy workflow.

My contribution

I assembled the workflow around microscopy data, created bounding-box annotations in LabelMe, prepared the dataset for object-detection training, ran training experiments, exported the trained model and created an interactive inference demonstration. Development was AI-assisted.

workflow()
Fluorescence microscopy images→LabelMe bounding boxes→Dataset conversion→Object-detection training→Model export→Interactive inference

What the prototype supports

  • Microscopy image preparation
  • Manual bounding-box annotation
  • Object-detection dataset preparation
  • YOLOv10-based model training in the project
  • TorchScript model export in the project
  • Gradio-based inference demonstration

Implementation note

The README documents a Python / PyTorch / Ultralytics training workflow and a Gradio demonstration. These are documented project technologies, not a blanket claim that I independently engineer in every framework.

AI-assisted development is disclosed openly. The scientific problem definition, workflow design and research context are the parts of the project I personally own; implementation depth continues to develop alongside my Master of Artificial Intelligence.
