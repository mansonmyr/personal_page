Probabilistic Colocalization Estimator

A ROI-centric bioimage analysis workbench for quantitative analysis of multichannel immunofluorescence TIFF images. The project was created around a real microscopy-analysis problem and provides an alternative workflow to conventional pairwise colocalization tools.

GitHub ↗Live demo ↗
Part of the OrganelleScope project history

PCE is a predecessor and migration source for OrganelleScope, which combines its colocalization workflow with QILP and additional analysis workspaces.

Explore OrganelleScope →

The problem

Traditional colocalization workflows are often pairwise. This prototype was designed to support multi-channel ROI analysis and bring several statistical readouts into one analysis workflow.

My contribution

I defined the microscopy-analysis needs, requested features, reviewed application behaviour and provided iterative feedback. AI coding tools generated and revised the implementation; my contribution focused on scientific requirements and workflow direction.

workflow()
Multichannel TIFF→ROI selection→Preprocessing→Colocalization / correlation→Regression-based profiling→Exportable results

What the prototype supports

  • Manders M1/M2 with Costes thresholding
  • Manders Overlap Coefficient
  • Pearson correlation
  • Likelihood-ratio-based discovery score
  • Multiple linear regression and standardized beta coefficients
  • Link Strength Ratio and R²
  • ROI phenotypic profiling
  • Rolling-ball background subtraction
  • Noise2Void-based denoising in the project workflow

Implementation note

The repository uses a Python backend and web-based frontend; implementation details are documented in the GitHub README. I treat these as project implementation details rather than claims of independent expertise in every framework.
