Semi-automated Microtubule Quantification with Fiji/ImageJ

A set of Fiji/ImageJ macros for semi-automated quantification of microtubule fluorescence intensity from immunofluorescence z-stacks, including centrosomal foci and mitotic spindle poles.

GitHub ↗

The problem

Microscopy quantification can involve repetitive preprocessing, detection and ROI placement. The macro workflow automates the repeatable parts while retaining a manual background-ROI adjustment step.

My contribution

I designed the analysis workflow from the microscopy experiment, translated the measurement logic into Fiji/ImageJ macros and documented the analysis sequence and interpretation choices.

workflow()
z-stack→Sum projection→Adaptive median / Gaussian / mean filters→Find Maxima→ROI generation→Background correction→Intensity output

What the prototype supports

  • Centrosomal microtubule intensity
  • Background-subtracted intensity
  • Spindle-pole γ-tubulin intensity
  • Spindle length from two detected poles
  • Spindle microtubule intensity
  • CSV-compatible outputs

Implementation note

The implementation is Fiji/ImageJ macro-based, with an external adaptive-median-filter plugin used in the preprocessing step. The repository contains the macro workflow and examples.

AI-assisted development is disclosed openly. The scientific problem definition, workflow design and research context are the parts of the project I personally own; implementation depth continues to develop alongside my Master of Artificial Intelligence.
