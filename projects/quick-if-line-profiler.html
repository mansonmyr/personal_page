Quick Immunofluorescence Image Line Profiler

A browser-based TIFF line-intensity profiler for 2-, 3- and 4-channel immunofluorescence images, created to make calibrated fluorescence line measurements quicker and easier to inspect.

GitHub ↗Live demo ↗
Part of the OrganelleScope project history

OrganelleScope combines QILP with PCE. Its integrated line profiler derives selected helpers, charting components, TIFF chart export and tests from QILP, with adaptations.

Explore OrganelleScope →

The problem

Line-profile analysis is useful for comparing spatial signal, but manual workflows can be repetitive. This prototype puts ROI selection, calibration, peak measurements and export into one browser interface.

My contribution

I defined the analysis workflow around immunofluorescence use cases, built and documented the prototype with AI-assisted coding, and specified the metrics and interpretation logic used by the interface.

workflow()
TIFF upload→Straight line ROI→Physical calibration→Channel sampling→Peak / FWHM / AUC analysis→CSV / JSON / TIFF export

What the prototype supports

  • 2–4 channel TIFF input
  • uint8 / uint16 image support
  • Physical pixel-size calibration
  • Optional rolling-ball background subtraction
  • Peak intensity and position
  • Detected peak count
  • FWHM measurements
  • AUC calculation
  • Quick metrics for multi-peak traces
  • CSV and JSON export

Implementation note
