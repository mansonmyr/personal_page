AI-assisted application · Devpost learning project · 2026

Won(da) Won

A MYR/KRW travel-rate dashboard for Malaysian travellers planning a trip to South Korea. The proof of concept combines rate charts, experimental target simulations and shared Signal Rooms.

GitHub ↗Live demo ↗Video demo ↗

The idea

Travellers and their companions can watch one currency pair and coordinate around a preferred exchange-rate target. The application brings rate history, recent publisher headlines and a shared target into one interface.

Project summary and my role

  • Directed the concept and requirements for a MYR/KRW dashboard with rate charts, experimental target simulations and shared Signal Rooms.
  • Used the Devpost Learn Skill Pack to structure scope, product requirements, technical planning and incremental build reviews for Build With AI: Basics.
  • Codex generated and revised the code; my role focused on product decisions, feature requests, application review and iterative feedback, rather than independent implementation.

From idea to proof of concept

Developed for Build With AI: Basics using the Devpost Learn Skill Pack. The guided process helped turn product decisions into scope, requirements, a technical specification and incremental build reviews.

Scope ↗Product requirements ↗Technical specification ↗

What it supports

Rate-history charts, experimental target simulations, Firebase Signal Rooms, shared targets, timed voting, connected-page alerts and recent publisher headlines.

What I learned

Practised defining a bounded product, documenting decisions, reviewing incremental changes and distinguishing implementation checks from real-world performance. The repository preserves forecast evaluations and the limitations of the proof of concept.

The application does not exchange money. Forecasts are experimental scenarios, not calibrated probabilities or guaranteed outcomes. Browser alerts require an open, connected page; the prepared email service is not yet activated.
