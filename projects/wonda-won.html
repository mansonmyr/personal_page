Won(da) Won — MYR/KRW Travel Decision-Support Application

A completed and deployed web application helping Malaysian travelers monitor MYR–KRW exchange rates and coordinate currency-exchange decisions for trips to South Korea.

GitHub ↗Live application ↗Video demo ↗

The idea

Travellers and their companions can watch one currency pair and coordinate around a preferred exchange-rate target. The application brings rate history, recent publisher headlines and a shared target into one interface.

Project summary and my role

  • Conceived a web application to help Malaysian travelers monitor MYR–KRW exchange rates and coordinate currency-exchange decisions for trips to South Korea.
  • Used AI-assisted development tools to translate product ideas into a functional web application with specified features including currency-rate visualizations, exchange-target simulations, regional news and collaborative Signal Rooms.
  • Prepared hackathon project scope, product requirements, technical specifications and implementation checks using the Devpost Learn Skill Pack; developed for hackathon submission (award or acceptance not claimed).

Codex generated and revised the implementation; my role focused on product ideas, requirements, feature requests, review and iterative feedback.

Hackathon planning and development

Developed for Build With AI: Basics using the Devpost Learn Skill Pack. The guided process helped turn product decisions into scope, requirements, a technical specification and incremental build reviews.

What it supports

Rate-history charts, experimental target simulations, Firebase Signal Rooms, shared targets, timed voting, connected-page alerts and recent publisher headlines.

What I learned

Practised defining a bounded product, documenting decisions, reviewing incremental changes and distinguishing implementation checks from real-world performance. The repository preserves forecast evaluations and the limitations of the application.

The application does not exchange money. Forecasts are experimental scenarios, not calibrated probabilities or guaranteed outcomes. Browser alerts require an open, connected page; the prepared email service is not yet activated.
